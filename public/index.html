How x402 Works

1

Request API

Client sends HTTP request to protected endpoint

→
2

402 Response

Server returns HTTP 402 with payment details

→
3

Sign & Retry

Client signs TX and retries with X-PAYMENT header

→
4

Access Granted

Server settles payment, returns data

Quick Integration

Server (Express.js)

import { x402PaymentRequired, STXtoMicroSTX } from 'x402-stacks';

app.get('/api/premium',
  x402PaymentRequired({
    amount: STXtoMicroSTX(0.001),
    address: 'SP1ZGGS886YCZHMFXJR1EK61ZP34FNWNSX32N685T',
    network: 'testnet',
  }),
  (req, res) => {
    res.json({ data: 'Premium content!' });
  }
);

Client (axios)

import { withPaymentInterceptor, privateKeyToAccount } from 'x402-stacks';

const account = privateKeyToAccount(privateKey, 'testnet');
const api = withPaymentInterceptor(axios.create(), account);

// Automatic payment handling!
const data = await api.get('/api/premium');
